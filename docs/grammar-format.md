# Формат файлу з КВ-граматикою

Кожен рядок - правило `A -> α | β | ...` (можна `→`). Аксіома - ліва частина першого правила.
Коментар починається з `#`.

- нетермінал: велика латинська літера, можна з цифрами або штрихом (`S`, `A1`, `S'`), або `<ім'я>`
- термінал: будь-який інший символ (`a`, `+`, `(`), або рядок у лапках `'begin'`
- порожній ланцюжок: `ε` або `eps`
- пробіли між символами необов'язкові: `S -> aSb` і `S -> a S b` - одне й те саме

Приклад:

    S -> aSb | ε
